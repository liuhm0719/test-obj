## Deploying this project (astra-deploy)

This project deploys through the Astra CICD platform. The deployment declaration lives in `astra.jsonc` at the repo root; the platform link anchor lives in `.astra/project.json`.

### Step 1 — check for the astra CLI

Run `astra --version` to see whether the astra CLI is available in this environment.

### Step 2a — astra CLI available

Run `astra deploy --env staging`. This reads the repo declaration files; configure your token under `~/.astra/profiles`.

### Step 2b — no CLI: use the gateway MCP server

Configure the gateway MCP server at `http://host.docker.internal:18080/mcp` (the bind token authenticates; get it from the platform Settings page — never write it into this repo). Read the repo's `astra.jsonc`, then pass its content as the spec parameter to the astra deployment tools.

### Step 2c — no CLI: call the gateway REST API directly

The gateway public base URL is not configured — ask the platform administrator for the deploy endpoint.

### Red lines (do not cross)

- Tokens and credentials never go into this repo or astra.jsonc.
- astra.jsonc `environments.vars` holds non-sensitive config only; sensitive values go through the platform-side config channel.
- This file is generated by devbox-gateway (version=1). Use the platform's repair flow to change it; do not hand-edit the version marker.
